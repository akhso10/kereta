# Gerbong Terakhir · Lintasan 13

Demo horor orang pertama berlatar perjalanan malam Arunika 13. Game ini berisi enam bab dan dua ending. Paket distribusi disiapkan untuk Windows x64 dan editor Godot 4.7.2 Standard.

Ekstrak paket Windows ke satu folder, lalu jalankan GerbongTerakhir.exe dengan GerbongTerakhir.pck di sebelahnya. Untuk mengedit game, ekstrak paket sumber dan impor Lintasan13/project.godot melalui Godot Project Manager.
